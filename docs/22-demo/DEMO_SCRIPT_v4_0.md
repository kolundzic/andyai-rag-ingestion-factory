# Demo Script v4.0.0

## One Command Demo

```bash
./scripts/run_operator_console_demo.sh
```

## What It Does

```text
ingest demo document
build vector index
run hybrid retrieval
build evidence pack
record governance audit
calculate readiness score
write JSON report
write HTML report
write release evidence bundle
```

## Demo Talking Points

1. This is not a PDF chatbot.
2. This is an ingestion-first RAG factory.
3. The system preserves source identity.
4. Retrieval is hybrid, not vector-only.
5. The answer context is evidence-backed.
6. The operator can inspect the report.
7. v4 makes the repo reviewable by outsiders.

## Public Line

```text
We do not just answer.
```

# Operator Evidence Console v4.0.0

## Purpose

v4.0.0 introduces the Operator Evidence Console layer.

This release makes the repo easier to inspect, demonstrate, explain, and trust.

## What It Adds

```text
operator evidence console
demo run orchestrator
readiness scoring
JSON report output
HTML report output
release evidence bundle
showcase script
```

## Why This Matters

A serious RAG ingestion factory should not only run.

It should show what happened.

The operator must be able to answer:

```text
What was ingested?
How many chunks were created?
Was retrieval tested?
Were citations generated?
Did governance audit pass?
Is the system ready for the next production step?
```

## Canonical Rule

```text
A system that cannot show its evidence cannot earn trust.
```

## v4 Formula

```text
Run the factory.
Collect the proof.
Score readiness.
Show the evidence.
Invite review.
```

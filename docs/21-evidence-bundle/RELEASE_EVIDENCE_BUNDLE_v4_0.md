# Release Evidence Bundle v4.0.0

## Purpose

The Release Evidence Bundle is the public proof layer for the repo.

It gathers:

- ingestion manifest
- retrieval results
- evidence pack
- audit summary
- readiness score
- generated report paths

## Bundle Outputs

```text
operator_console_report.json
operator_console_report.html
release_evidence_bundle.json
```

## Why It Exists

Most demos only show final output.

AndyAI shows the evidence path.

## Canonical Rule

```text
No evidence bundle, no serious release.
```

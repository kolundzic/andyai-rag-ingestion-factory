# Release Notes — v16.9.0

## Release Name

Pilot Intake Admin Review Layer

## Summary

v16.9.0 adds an operator/admin review layer for pilot requests.

## Included

- Pilot Intake Admin Review Layer docs
- Admin Queue Spec
- Pilot Review Decision Model
- Admin Review Playbook
- Admin Review Copy Bank
- Pilot Admin Roadmap
- pilot admin schemas
- sample admin queue examples
- `/pilot-admin` page
- `/api/pilot-request/admin-demo` route
- `pilotAdminReview.ts` data model
- verification script
- README update

## Canonical Rule

```text
A pilot request is not complete when it is submitted. It is complete when an operator can review it, score it, and decide the next action.
```

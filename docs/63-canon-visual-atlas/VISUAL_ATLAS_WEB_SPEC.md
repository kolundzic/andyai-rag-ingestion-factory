# Visual Atlas Web Spec

## Route

```text
/visuals/atlas
```

## Purpose

The page presents the 14 official diagrams as one coherent atlas.

## User Experience

Each visual should show:

```text
title
category
description
image
file path
canon status
```

## Categories

```text
Core Knowledge Factory
Governance and Trust
Runtime and Deployment
```

## Canonical Rule

```text
The visual atlas is not decoration. It is the public explanation layer of the factory.
```

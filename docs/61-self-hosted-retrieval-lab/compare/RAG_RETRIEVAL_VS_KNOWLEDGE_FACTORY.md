# RAG Retrieval vs Knowledge Factory

| Layer | Ordinary RAG | AndyAI Knowledge Factory |
|---|---|---|
| Purpose | Find relevant chunks | Build durable knowledge |
| Output | Answer | Evidence-backed knowledge object |
| Memory | Often temporary context | Persistent wiki, graph, and approval state |
| Trust | Depends on retrieved text | Evidence packs and human governance |
| Structure | Usually flat fragments | Wiki pages, claims, graph nodes, graph edges |
| Governance | Often weak | Human approval, audit trail, permissions |
| Reuse | Limited | Approved knowledge reused in workflows |

## Canonical Sentence

```text
RAG finds fragments.
Knowledge Factory turns them into proven, linked, approved knowledge.
```

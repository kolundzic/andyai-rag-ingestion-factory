# Story Mode Operator Script

## Purpose

This script helps AndyAI operators explain the Visual Atlas in a meeting, demo, or client call.

## Opening

```text
We started from a simple but difficult question: how do we ingest 100–200 PDFs, each around 1,000 pages?
```

## Core Explanation

```text
Ordinary RAG retrieves fragments.
AndyAI Knowledge Factory turns fragments into evidence-backed, structured, human-approved knowledge.
```

## Walkthrough

1. Show the massive PDF problem.
2. Explain ingestion as the first discipline.
3. Explain RAG as retrieval, not the whole factory.
4. Show evidence packs as the trust layer.
5. Show human approval as governance.
6. Show architecture and runtime.
7. End with the product surface and public site.

## Closing

```text
This is not a chatbot over files. This is a governed knowledge production system.
```

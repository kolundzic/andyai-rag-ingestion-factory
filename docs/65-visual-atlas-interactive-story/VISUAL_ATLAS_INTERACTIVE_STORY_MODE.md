# v16.6.0 — Visual Atlas Interactive Story Mode

## Mission

Turn the Visual Atlas Product Demo Layer into a step-by-step guided story experience.

## Product Role

The story mode helps a visitor understand the whole system in sequence:

```text
problem
ingestion
retrieval
evidence
governance
architecture
runtime
product
```

## Canonical Rule

```text
A serious product should not only show its architecture — it should guide the user through it.
```

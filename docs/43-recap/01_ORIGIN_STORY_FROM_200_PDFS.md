# Origin Story — From 200 PDFs to a Sovereign Knowledge Factory

## The Question

The project began with a simple, practical question:

```text
How do we ingest 100–200 PDFs,
each with around 1,000 pages?
```

That question was not small.

It contained the real enterprise problem:

```text
too many documents
too many pages
too much hidden knowledge
too much risk if retrieval is wrong
too much need for citations, metadata, permissions, and governance
```

## The Click

The idea immediately expanded:

```text
This is not just a PDF ingestion problem.
This is a Knowledge Factory problem.
```

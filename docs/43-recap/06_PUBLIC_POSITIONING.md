## Value

AndyAI Knowledge Factory helps teams transform large document collections into controlled, searchable, citable, permission-aware knowledge systems.

## What It Is Not

- not a generic chatbot
- not a simple PDF upload demo
- not prompt-only automation
- not vector search without governance

## What It Is

- ingestion discipline
- metadata memory
- permission-aware retrieval
- evidence packs
- Context Boards
- cited drafts
- approval workflows
- operator visibility
- release governance

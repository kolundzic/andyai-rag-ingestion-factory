# Architecture Evolution

## Stage 1 — Ingestion

```text
Files → registry → parser → chunks → manifest
```

## Stage 2 — Retrieval

```text
Chunks → keyword index + vector index → hybrid retrieval
```

## Stage 3 — Evidence

```text
Retrieval candidates → reranker → evidence pack → citations
```

## Stage 4 — Governance

```text
Evidence → audit → readiness → operator report
```

## Stage 5 — Sovereign Enterprise

```text
Permissions → Context Board → Draft → Approval → External Gateway
```

## Stage 6 — Knowledge OS

```text
Runtime → tenants → observability → release factory → knowledge OS canon
```

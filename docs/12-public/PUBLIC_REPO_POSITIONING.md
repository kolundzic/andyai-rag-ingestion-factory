# Public Repo Positioning

## Repository

**andyai-rag-ingestion-factory**

## One-Line Description

Production-grade RAG ingestion factory for large PDF libraries, with page-level citations, metadata governance, and hybrid retrieval architecture.

## Public Position

This repository is not a simple PDF chatbot.

It is a governed ingestion factory for building reliable RAG systems over large PDF collections.

## Core Audience

- AI engineers
- RAG developers
- document intelligence builders
- enterprise knowledge-base teams
- researchers working with large PDF libraries
- technical founders building retrieval systems

## Why It Matters

Most RAG failures begin before retrieval.

They begin in ingestion:

```text
bad parsing
bad chunking
missing metadata
lost page numbers
weak citations
untracked pipeline runs
```

This repo treats ingestion as a first-class engineering system.

## Strong Public Formula

```text
No ingestion discipline, no RAG truth.
```

## What Makes It Different

- page-aware design
- metadata-first architecture
- PostgreSQL system-memory layer
- parser adapter structure
- citation pack standard
- visual README canon
- GitHub-friendly public documentation
- AndyAI governance philosophy

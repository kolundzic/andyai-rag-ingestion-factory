# Client Pitch Flow

## Recommended Pitch Sequence

```text
1. Problem — document chaos is expensive
2. Risk — ordinary RAG can retrieve but not govern knowledge
3. Solution — Knowledge Factory builds evidence-governed knowledge
4. Visual proof — the atlas shows the full system
5. Workflow proof — ingestion, retrieval, evidence, approval, export
6. Trust proof — human approval, permissions, evidence packs
7. Runtime proof — Supabase, Vercel, multi-tenant readiness
8. Pilot offer — start with a controlled document collection
9. Success metric — reduce search time, improve traceability, improve reuse
10. Next step — pilot request / demo meeting
```

## Canonical Pitch Line

```text
Your PDFs should not remain dead archives. They should become governed, reusable knowledge infrastructure.
```

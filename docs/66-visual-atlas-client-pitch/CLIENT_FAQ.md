# Client FAQ

## Is this just another RAG app?

No. RAG is the retrieval layer. AndyAI Knowledge Factory adds evidence packs, structured synthesis, knowledge graph direction, human approval, visual explanation, and operational workflow control.

## How does the system reduce hallucination risk?

The system uses strict context answering, source traceability, evidence packs, approval workflows, and clear distinction between AI proposals and approved knowledge.

## What is the best way to start?

Start with a focused pilot: a limited document collection, clear users, clear questions, evidence-backed outputs, and a review workflow.

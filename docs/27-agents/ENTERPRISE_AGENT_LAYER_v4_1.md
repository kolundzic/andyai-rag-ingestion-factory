# Enterprise Agent Layer v4.1.0

## Purpose

This blueprint defines future enterprise agents built on top of the ingestion factory.

## Agent Types

```text
Ingestion Agent
Retrieval Agent
Evidence Agent
Context Board Agent
Drafting Agent
Compliance Agent
Operator Review Agent
External Service Gateway Agent
```

## Agent Rule

```text
Agent never just claims.
Agent must carry evidence.
```

## Human-in-the-Loop Rule

Agents may prepare, retrieve, summarize, compare, and draft.

Humans approve external use, sensitive outputs, and permission boundary changes.

## Future Implementation

v4.3+ should add typed agent task schemas and bounded action contracts.

# Visual Atlas Layer

## Purpose

The Visual Atlas is the human understanding layer above wiki and graph structures.

It allows knowledge to be explored as:

```text
map
space
flow
hierarchy
relationship network
evidence trail
```

## Canonical Rule

```text
Structured knowledge should be visible, not only searchable.
```

## Future Direction

v14+ can connect the Visual Atlas to:

```text
graph views
topic maps
evidence paths
claim networks
approval status overlays
```

# Hierarchical Knowledge Graph Standard

## Purpose

The Hierarchical Knowledge Graph organizes knowledge by levels.

## Levels

```text
domain
topic
subtopic
entity
claim
evidence
source
contradiction
```

## Example

```text
AI Governance
→ Retrieval-Augmented Generation
→ Permission-Aware Retrieval
→ Claim: “Permissions must shape retrieval before context reaches the model.”
→ Evidence Pack
→ Source Document
```

## Canonical Rule

```text
Knowledge must be linked, not only listed.
```

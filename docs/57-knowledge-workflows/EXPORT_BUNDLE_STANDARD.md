# Export Bundle Standard

## Purpose

Export Bundles allow approved knowledge to leave the factory safely.

## Export Targets

```text
markdown
json
wiki_page
client_report
notion_pack
public_page
api_payload
```

## Export Requirements

```text
approval_status
evidence_refs
source_refs
export_policy
created_by
created_at
```

## Canonical Rule

```text
External exports require approval and evidence.
```

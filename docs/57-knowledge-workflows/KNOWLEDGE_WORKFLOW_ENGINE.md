# Knowledge Workflow Engine

## Purpose

The Knowledge Workflow Engine turns knowledge objects into operational sequences.

## Workflow Types

```text
wiki_compile
claim_review
graph_enrichment
evidence_export
draft_generation
visual_atlas_review
client_report
```

## Workflow Lifecycle

```text
created
queued
running
waiting_for_review
approved
rejected
exported
archived
```

## Canonical Rule

```text
No workflow output should lose its evidence chain.
```

# Pilot Request Form Spec

## Route

```text
/pilot-request
```

## Required Fields

```text
name
email
organization
document_count_range
document_type
primary_domain
main_problem
success_criteria
privacy_level
pilot_timeline
notes
```

## Document Count Options

```text
20–50 documents
50–200 documents
200–1,000 documents
1,000+ documents
```

## Privacy Levels

```text
public / demo-safe
internal business documents
regulated / confidential
unknown / needs review
```

## Canonical Rule

```text
Do not collect documents first. Collect pilot scope first.
```

# Pilot Qualification Matrix

| Signal | Good Fit | Risk |
|---|---|---|
| Clear document set | Yes | vague scope |
| Clear business pain | Yes | curiosity only |
| Human reviewer available | Yes | no owner |
| Evidence traceability needed | Strong fit | weak fit |
| Confidential documents | possible | needs privacy review |
| Wants instant magic | weak fit | expectation risk |

## Qualification Output

```text
green = ready for pilot
yellow = needs scoping call
red = not ready / needs education
```

# v16.8.0 — Pilot Request Conversion Layer

## Mission

Turn the Client Pitch Mode into a concrete pilot-request conversion path.

## Canonical Sentence

```text
A pitch without a pilot path is only a presentation.
```

Serbian:

```text
Pitch bez pilot puta je samo prezentacija.
```

## Product Role

The layer helps a potential client move from:

```text
interest
→ qualification
→ document-scope definition
→ pilot request
→ review
→ next meeting
```

## Conversion Goal

The user should understand exactly what to bring for a pilot:

```text
document collection
domain / department
main questions
expected users
privacy constraints
success criteria
timeline preference
```

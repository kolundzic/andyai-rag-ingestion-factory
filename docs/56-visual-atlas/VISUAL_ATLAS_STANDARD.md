# Visual Atlas Standard

## Purpose

The Visual Atlas is the layer that helps humans understand knowledge structures quickly.

## Visual Modes

```text
domain map
topic map
entity network
claim network
evidence path
approval overlay
contradiction map
wiki-to-graph bridge
```

## Design Principles

- clarity first
- evidence visible
- approval visible
- contradiction visible
- hierarchy readable
- human-friendly before machine-clever

## Canonical Rule

```text
Every important visual must preserve evidence traceability.
```

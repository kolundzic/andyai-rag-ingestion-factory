# Pilot Request Runtime Adapter

## Purpose

The runtime adapter defines how the application should submit, list, and summarize persisted pilot requests.

## Operations

```text
create_pilot_request
list_pilot_requests
summarize_pilot_requests
update_review_status
```

## v17.0.1 Scope

This release adds a local/demo adapter contract and sample payloads.
A future release should wire this to real Supabase client calls.

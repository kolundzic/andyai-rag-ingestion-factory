# Admin Review Playbook

## Step 1 — Read the Request

Check:

```text
organization
document count
document type
domain
main problem
success criteria
privacy level
timeline
```

## Step 2 — Score the Fit

Use the qualification result:

```text
green = ready for pilot scoping
yellow = needs scope clarification
red = not ready
```

## Step 3 — Decide Status

```text
new → reviewing
reviewing → approved_for_pilot
reviewing → needs_scope
reviewing → rejected
```

## Step 4 — Write Review Notes

Review notes must explain:

```text
why this request is promising
what risk exists
what question must be asked next
what concrete next action is required
```

## Step 5 — Trigger Next Action

Possible next actions:

```text
schedule pilot review call
ask for document sample description
send pilot proposal
request privacy review
politely decline
```

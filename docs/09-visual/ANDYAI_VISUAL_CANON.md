# AndyAI Visual Canon — RAG Ingestion Factory

## Purpose

This visual canon defines how the repository should present itself in GitHub, docs, and future public materials.

The goal is:

```text
technical clarity + product dignity + visual proof + AndyAI identity
```

## Color Logic

- 🔵 Blue = registry / source / metadata
- 🟣 Purple = parsing / OCR / structure
- 🟠 Orange = chunking / embedding / indexing
- 🟢 Green = retrieval / evidence / validation
- 🔴 Red = failure / risk / governance alert
- ⚪ Neutral = storage / notes / supporting context

## Diagram Rule

Each major diagram should show:

```text
input → processing → storage → retrieval → evidence
```

## Icon Rule

Every major section in README should have a visible icon.

## Canonical Statement

```text
Beautiful is good.
Beautiful and verifiable is AndyAI.
```

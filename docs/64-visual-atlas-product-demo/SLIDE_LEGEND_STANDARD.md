# Slide Legend Standard

Every canonical diagram must include a textual legend.

## Required Fields

```text
Title
One-line meaning
What this shows
Why it matters
Key elements
Process flow
Practical takeaway
AndyAI angle
```

## Why

A diagram without a legend can impress.
A diagram with a legend can teach.

## Canonical Rule

```text
Every diagram must explain itself to a serious beginner.
```
